# PRRDB 2.0: Pattern-Recognition Receptors & Ligands Database

Welcome to the official repository for **PRRDB 2.0**, a comprehensive and manually curated database of pattern-recognition receptors (PRRs) and their ligands. This resource is designed for researchers working in immunology, innate immunity, host-pathogen interactions, computational biology, and bioinformatics.

Web Server: https://webs.iiitd.edu.in/raghava/prrdb2/

# About the Database

PRRDB 2.0 is an updated version of the original PRRDB database that maintains detailed information on pattern-recognition receptors (PRRs) and their ligands, including pathogen-associated molecular patterns (PAMPs).

The database compiles experimentally validated information collected from research articles and public biological databases. It provides comprehensive annotations related to receptor classification, ligands, structures, sequences, origin, and immune functions.

The database was manually curated from:

* Research articles
* Public biological databases
* Swiss-Prot
* PubChem
* Protein Data Bank (PDB)

---

# Key Features

## Large Curated Dataset

* ~2700 total entries
* 467 unique PRRs
* 827 unique PAMPs
* Data curated from ~600 research articles
* ~4500 experimentally determined structures linked from PDB

---

## Comprehensive Annotations

Each entry contains detailed information including:

* PRR name
* Ligand/PAMP information
* Sequence data
* Source organism
* Receptor type
* Origin
* Structural information
* Functional annotation
* External database links

---

## Structural Information

PRRDB 2.0 provides:

* Experimentally determined structures from PDB
* Predicted structures for 110 PRRs lacking experimental structures
* Structure-function relationship information

Structural annotations support advanced immunological and computational studies.

---

# Major PRR Families Included

The database contains information related to major pattern-recognition receptor families such as:

* Toll-like receptors (TLRs)
* C-type lectin receptors (CLRs)
* NOD-like receptors (NLRs)
* RIG-I-like receptors (RLRs)
* Scavenger receptors
* Mannose receptors
* β-glucan receptors

---

# Integrated Analysis Tools

PRRDB 2.0 integrates several bioinformatics tools to help users analyze receptor and ligand sequences:

* BLAST Search
* Smith-Waterman Similarity Search
* Advanced Search Module
* Browsing and Categorization Tools

These tools allow users to:

* Perform sequence similarity analysis
* Explore receptor-ligand relationships
* Browse PRRs based on source and type
* Retrieve structure and functional information

---

# Browse and Search Options
